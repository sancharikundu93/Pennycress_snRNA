# Pennycress root snRNA-seq — 3D UMAP (beta)

> **Beta.** Preliminary, unpublished data. Clusters, labels and layout may change.

Interactive 3D UMAP of *Thlaspi arvense* (pennycress) root single-nucleus RNA-seq, Control vs Salt.

**View:** https://sancharikundu93.github.io/Pennycress_snRNA/

| Page | What it is |
|---|---|
| `index.html` | Auto-rotating 3D UMAP; drag to inspect (pauses spin) |
| `interactive.html` | Static-camera plotly view; rotate/zoom/hover by hand |

- 25,206 nuclei (Control 13,362 · Salt 11,844)
- 23 clusters (Seurat resolution 0.6), 19 annotated cell types
- Both pages are single self-contained files and work offline.

Generated by `scripts/23_umap3d_rotate90.R` and `scripts/24_umap3d_interactive_html.R`.
